# Afterthought

Afterthought is a quiet, offline three-minute reflection tool for the moment after a high-pressure meeting. It is not medical care and does not interpret or score you.

## Launch

Double-click `afterthought.html`. It opens directly in a modern browser; there is no install, build, or internet connection required.

## Verify

From this folder, run `node tests/verify.mjs` for the static offline/privacy check. For a browser check, open the HTML, click Begin, enter a note, refresh, and click Begin again to see the note restored. Complete or skip the four stages, then use Clear local note and confirm the draft is gone after starting again.

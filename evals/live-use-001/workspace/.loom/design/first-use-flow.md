# Three-minute reflection experience

After a tense meeting, Afterthought gives the user a quiet, finite ritual: notice the body, name what happened, separate what is theirs to carry, and choose one next step. It never scores the user or tells them what they feel.

The user sees a calm landing screen, then four optional stages: Arrive, Name, Sort, and Next. Each stage has one prompt, free text, Skip, Back, and Continue. The closing screen mirrors only the user's words. It includes Copy summary, Start over, and Clear local note.

Use restrained editorial typography, warm paper/ink colors, and direct language. Avoid clinical labels, ratings, diagnoses, crisis claims, or prescriptive advice. Include: reflection tool, not medical care.

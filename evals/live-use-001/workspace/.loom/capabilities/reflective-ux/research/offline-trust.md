# Trust through local-first interaction

Source: Project-specific privacy UX analysis (agent-authored, 2026-09-12)

When notes may be sensitive, a responsible interface makes the storage boundary legible at the moment of use, avoids network dependencies, and gives the user a plainly named deletion action. Persistence should be resilient to refresh but not silently become an account or cloud system. Verification combines source inspection with an observed save/reload/delete flow because a privacy promise that is not tested is only copy.

The counterexample is a browser feature that blocks storage for local files or a future edit that adds a remote font/analytics script. Therefore the artifact should degrade gracefully and its release check should flag external URLs and fetch-like primitives.

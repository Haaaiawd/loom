# Bounded reflection and user agency

Source: Project-specific design synthesis informed by reflective-practice facilitation patterns (agent-authored, 2026-09-12)

For a person leaving a high-pressure conversation, a practitioner should reduce cognitive load before asking for interpretation: offer a short container, one concrete prompt at a time, and permission to skip. Prompts should elicit observations and the user's own language rather than label an emotion or imply a correct response. A useful output is a small next action chosen by the person, not a recommendation generated by the tool.

The practitioner keeps the boundary visible: reflection can support sense-making but is not treatment. A summary should mirror authored text faithfully and provide an exit/clear path. The counter-risk is over-framing: too many steps, timers, or therapeutic language can make a supposedly gentle tool feel like an assessment.

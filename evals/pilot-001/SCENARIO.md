# Pilot 001 — Daily Re-entry Tool for a Small Indie Game Team

## Raw brief shown to both conditions

请帮我做一个 Windows 本地桌面工具，帮助小型独立游戏团队每天快速进入工作状态并知道下一步做什么。它可以读取现有项目。先把项目设计清楚，并做出第一个可运行的纵向原型。

## Controlled setup

- Condition A: normal capable Agent, no LOOM.
- Condition B: the same Agent model and tools, with LOOM available.
- Both receive identical seed files and the same user oracle.
- Each first produces one question round.
- After shaping, context is forcibly reset and a fresh Agent implements the first vertical slice from disk only.
- This is one directional pilot, not a repeated statistical result.

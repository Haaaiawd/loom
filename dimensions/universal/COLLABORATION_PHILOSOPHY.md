# Doctrine Lens — Collaboration and Decision Rights

> 按需使用。单人、低冲突项目不需要制造一套治理制度。

## 触发

- 多个角色或团队对同一决定拥有不同责任。
- 重要分歧反复拖慢或破坏交付。
- 变更需要明确授权、影响评估或审计。
- 人类与 Agent 的决策边界不清晰。

## 决策问题

1. 哪类决定由谁负责，谁提供意见，谁最终批准？
2. 事实分歧、价值分歧和授权分歧分别如何解决？
3. 什么变更需要影响评估，什么可以直接可逆实验？
4. 何时必须升级给人类，何时 Agent 应自主推进？
5. 哪些协作行为会制造虚假共识、责任漂移或文档表演？

## 输出标准

- 只覆盖真实存在的决策类型。
- 权限与升级条件清楚。
- 评审标准关注结果、契约和风险，不管理个人风格。
- 规则包含例外和退出条件。
- Evidence Map 记录导致规则产生的真实冲突或外部依据。

协作 Doctrine 不复制角色提示词；角色权限由 LOOM System Boundary 管理。
